关于这个游戏

这个「别踩白块」是用 vibe coding（AI 辅助编程）从零做出来的：先跟 AI 描述玩法，AI 生成代码，我再试玩反馈，几轮迭代就完成了。

  • 原生 HTML / CSS / JavaScript，零依赖、零构建
  • 音效用 Web Audio 实时合成，无需任何音频文件
  • 最高分本地保存，随时回来挑战
  • 支持手机触控与键盘操作

欢迎到 GitHub 查看源码与制作过程 👉 vibe-coded-piano-tiles
